# Personal-Projects

El siguiente repositorio contiene mis projectos personales

## Proyectos

- [anti-procrastinacion](anti-procrastinacion/): tres apps de escritorio contra la procrastinación: **plazos** (entregas y costo de postergar), **foco** (bloques con intención) y **bloqueo** (sitios y apps que distraen), y la app de iPhone **Al día** con plazos y foco.
- [sociallite](sociallite/): **SocialLite**, Instagram sin doomscrolling, para iPhone y como extensión de navegador. Los mensajes siempre quedan libres; el resto tiene un tiempo diario, y no hay Reels, Explorar, publicidad ni sugerencias. Todo funciona en local.
